* 質問：アクセントの情報は取得できますか？

````{admonition} コラム：中国人の Pythonista が勧めるトーク
こんにちは、卿学童（[ケイ ガクドウ](https://x.com/keishonagon)）と申します。中国出身で大学で日本語を専攻していますが、趣味で Python を独学しています。

私にとって最も影響の大きかった中国語の Python 書籍を1冊挙げるなら、必ず朱雷氏の[『Python クラフトマン』](https://github.com/piglei/one-python-craftsman)を選びます。今回の講演は、主にこの書籍の第13章と、彼のブログ記事[『import-linter を利用して Python プロジェクトのアーキテクチャを整理する』](https://www.piglei.com/articles/use-import-linter-to-lint-proj-arch/)を元に、Python プロジェクトにおける依存関係をどう標準化するかについて解説しました。

モジュールの結合・分割やパラメーターの簡素化、遅延実装など、他の言語でも一般的に用いられるテクニックに加え、 `typing.Protocol` を使って依存関係逆転を実現し、完全に疎結合にする手法についても紹介しました。

低レイヤーのモジュールである `users` が、高レイヤーのモジュール `marketing`内の SMS 送信に関連するコードに依存しているケースで説明されました。

```python
from marketing import SmsSender

class User:
    """簡単なユーザーオブジェクト"""

    def __init__(self):
        self.sms_sender = SmsSender()

    def add_notification(self, message: str, send_sms: bool):
        """ユーザーに新しい通知を送信する"""
        # ...
        if send_sms:
            self.sms_sender.send(message)
```

修正されたあとのバージョン：

```python
from typing import Protocol

class SmsSenderProtocol(Protocol):
    def send(message: str):
        ...

class User:
    def __init__(self, sms_sender: SmsSenderProtocol):
        self.sms_sender = sms_sender
```
````

````{admonition} コラム：PyCon 初登壇の感想
具体的な操作ステップの解説には、あえてテレビアニメ『BanG Dream! It's MyGO!!!!!』の名台詞「[なんで春日影やったの!?](https://dic.pixiv.net/a/%E3%81%AA%E3%82%93%E3%81%A7%E6%98%A5%E6%97%A5%E5%BD%B1%E3%82%84%E3%81%A3%E3%81%9F%E3%81%AE%21%3F)」を選びました。

1. 「なんで」や「春日影」、そして感動詞の「やった」が、現行の SudachiDict に全て未収録で、未登録語のテストケースとして非常に理想的だったからです。
2. このセリフが中国の若者の間で[ミーム化](https://dic.pixiv.net/a/%E3%81%AA%E3%82%93%E3%81%A7%E6%98%A5%E6%97%A5%E5%BD%B1%E3%82%84%E3%81%A3%E3%81%9F%E3%81%AE%21%3F#h2_2)するなど、絶大な影響力を持っているからです。私が「このフレーズをテストに使うよ」と伝えたところ、会場の多くの聴衆が笑ってくれました。
````

## 中国のインターネットとアプリ事情

筆者は今回初めて中国を訪問しましたが、インターネットやアプリについて色々と気をつける点があるので、そのことを共有したいと思います。

### インターネットはVPNが必要

まず中国でインターネットに接続すると[グレート・ファイアウォール](https://ja.wikipedia.org/wiki/%E3%82%B0%E3%83%AC%E3%83%BC%E3%83%88%E3%83%BB%E3%83%95%E3%82%A1%E3%82%A4%E3%82%A2%E3%82%A6%E3%82%A9%E3%83%BC%E3%83%AB)があるため、普段使っているさまざまなサービスが使用できません。
よく使うサービスだとGmail、Googleドライブ、YouTubeなどのGoogleのサービス全般、X(Twitter)、Facebook、GitHubなどが使用できません。
これらのサービスを使用するために多くの人はVPNを使用しているようです。

筆者はTrip.comが提供している、中国からでも各種サービスに接続可能なeSIMを使用しました。
PCからアクセスする場合は、スマートフォンからテザリングしていました。
おかげで現地でGmailやX(Twitter)への投稿が問題なくできました。
他にはahamoの国際ローミングでも各種サービスは利用可能なようです。

* 参考：[中国本土・香港・マカオ 5G eSIM | TikTok対応 | デイパス・データパッケージ | 1～30日間 | 24時間課金 | QRコード | Trip.com](https://jp.trip.com/things-to-do/detail/40017785)

PyCon Chinaの発表を見ていると、普通にGitHubとかX(Twitter)の情報をスライドに載せているので、みなさん基本的にVPNを使っているようです。

### 地図アプリ

接続ができてもまだ問題はあります。
中国に行く前に事前にホテルからLEGOLAND上海へのルートを調べようとしました、するとGoogleマップでは徒歩と自動車のルートしか出てきません。
そうです、Googleマップでは中国の電車を使ったルート検索ができないのです。
調べてみると地図アプリとしては「高徳地図」または「百度地図」を使用するのが一般的のようです。

筆者は高徳地図をインストールして利用していました。
ただ、目的地名などを中国語で正しく入力することが難しいため、ルート検索などはなかなか大変でした。


```{figure} images/googlemap.png
:width: 400

Googleマップのルート検索では徒歩か自動車しか出ない
```

### QRコード決済アプリ

中国ではQRコード決済が基本です（物乞いの方にも広まっています）。
決済手段としてはAlipayまたはWeChat Payのどちらかを使用します。
筆者はAlipayにSony Bank WALLETのVisaデビットを紐付けて使用していました（すぐに決済金額がわかるので安心です）。

ビールを飲んだとき、コンビニでの買い物など地下鉄以外はすべてAlipayで決済していました。
アプリの使い方が分からないときも、画面を見せると店員さんが代わりに操作してくれるのでなんとかなりました。

また、Alipayの中からDiDi（タクシーアプリ）を使用できるため、タクシーの支払いもAlipayで行えて便利でした。

### コミュニケーションはWeChat

チャットコミュニケーションとしてはWeChatが主流のようで、スピーカーへの連絡にWeChatのグループチャットが使用されていました。
筆者はWeChatアカウントを持っていないため、台湾のRex氏からスピーカーへの連絡事項を教えてもらっていました。
その後WeChatアカウントをとりあえず作成し、スピーカーのグループにRex氏が招待してくれたので、他のスピーカーや主催者と事前の連絡が取れるようになりました。

WeChatはチャット画面の中で翻訳が実行できるため、中国語でアナウンスがあっても翻訳してなんとなく読めるので便利です。

* 参考：[WeChatのトークを日本語にするなら「翻訳機能」 | 中華スマホ研究室](https://kokuei.world/phones/wechat-translate/)
